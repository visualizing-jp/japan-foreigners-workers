# 出典

厚生労働省「外国人雇用状況」の届出状況。報道発表の一覧は次のとおり。

https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyou/gaikokujin/gaikokujin-koyou/06.html

各年10月末時点の別表を使う。

- 別表1: 国籍別・在留資格別外国人労働者数
- 別表2: 都道府県別の事業所数と外国人労働者数
- 別表3: 都道府県別・在留資格別外国人労働者数

届出の対象は、事業主に雇用される外国人労働者。特別永住者と在留資格「外交」「公用」は除く。公表値は届出件数。

別表の Excel が残っているのは平成28年（2016年）から令和7年（2025年）まで。2008–2015年の報道発表は PDF だけで、このサイトには入れていない。2018–2020年のファイルは現在の厚労省サイトから消えているため、国立国会図書館 WARP のコピーを使う。URL は `src/lib/data/sources.ts`。

在留資格は、表の6つのまとまりだけを積む。「うち特定技能」「うち留学」などの内数は足さない。6つの和が、その行の総数と一致することを `npm run verify` で確かめている。都道府県の和と事業所数の和も、全国計と一致する。

2024年と2025年の全国計と、ベトナム・中国・フィリピンの人数は、報道発表の本文と一致する。令和6年の［参考-4］には訂正がある。使うファイルは報道発表ページに今ある Excel で、照合しているのは別表1の人数。

国籍は、その年の表で行になっている国だけ。インドネシアは2018年から、ミャンマーは2022年から、タイは2023年から、スリランカは2024年から、インドは2025年から分かれている。それ以前は「その他」に含まれる。G7等は表の注にある国のまとまりで、年によって範囲が違う。中国は「香港、マカオを含む」（2016年の表は「香港等を含む」）。
